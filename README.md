# مساعد تفاعلي لتعلّم الصلاة

مشروع هاكثون في مسار الذكاء الاصطناعي والرؤية الحاسوبية للحلول التعليمية.

## الفكرة

حل تعليمي تفاعلي يستخدم كاميرا الهاتف لتتبّع وضعيات الجسم وتسلسل خطوات الصلاة أثناء التدريب، ثم يعرض ملاحظات قصيرة تساعد المتدرّب على مراجعة الحركة وإعادتها.

## المشكلة

تشرح المواد التقليدية خطوات الصلاة، لكنها لا تتابع تطبيق المتعلّم ولا تحدد له موضع الحركة الذي يحتاج إلى مراجعة.

## الحل

يعرض الحل نموذجًا مرئيًا للحركة، ويستخدم تقدير وضعية الجسم وتحليل تسلسل الحركة لمقارنة الأداء بنموذج مرجعي تعليمي. تظهر ملاحظة موجزة عند اكتشاف اختلاف واضح، ثم يعرض ملخصًا للتقدّم.

## التقنيات المقترحة

- **MediaPipe Pose أو MoveNet:** استخراج نقاط الجسم من إطارات الكاميرا.
- **OpenCV:** تجهيز الإطارات عند الحاجة.
- **تحليل زمني للحركة:** متابعة الانتقال بين الوضعيات وحساب زوايا مختارة.
- **Flutter أو تطبيق هاتف مكافئ:** بناء واجهة التدريب وعرض الملاحظات.
- **قواعد تعليمية مراجعة:** تحويل نتائج التحليل إلى توجيهات واضحة.

## الأثر المتوقع

تقديم تجربة تعلّم عملية، وتسهيل إعادة التدريب على الحركات التي تحتاج إلى مراجعة، وقياس تحسّن وضوح التوجيه ودقة رصد الوضعيات.

## نطاق النموذج الأولي

الملف الحالي يقدّم وصف الفكرة والتصميم الأولي. نموذج الرؤية الحاسوبية وتطبيق الهاتف ما زالا ضمن خطة التطوير، ولم يُنفذا بعد.

## حدود الاستخدام

النتائج إرشادات تدريبية مبنية على الهيئة الظاهرة. لا يقيّم النظام النية أو الخشوع ولا يصدر حكمًا فقهيًا على صحة الصلاة. تُراجع المواد والنماذج المرجعية من مختصين قبل اعتمادها.

# Interactive Prayer Learning Assistant

A hackathon concept in AI and computer vision for interactive learning. The proposed mobile solution uses pose estimation and motion sequence analysis to provide short, practical feedback during training. This repository currently contains the project proposal and technical outline; the computer-vision model and mobile application are planned work, not implemented software.
