# صلاتي | مساحة تدريب خاصة

تطبيق ويب عربي يساعد على التدريب على قراءة نصوص الصلاة ومراجعتها، مع إرشادات لحركات الصلاة. يعمل التعرف على الصوت داخل المتصفح، وتُحفظ النتائج والتسجيلات على جهاز المستخدم.

## الميزات

- اختيار نص للتدريب، وعرض النص كاملًا في وضع **بمساعدة** أو إخفاؤه في وضع **دون مساعدة**.
- مراجعة محلية للصوت باستخدام نموذج Whisper Tiny العربي، ثم مقارنة الكلمات المسموعة بالنص المحدد.
- مراجعة الكلمات كلمةً كلمة، وتشغيل قراءة مرجعية بصوت الجهاز للمقارنة.
- كاميرا أمامية وخلفية، وتسجيل محلي قابل للتنزيل.
- تقدير بصري تقريبي للقيام والركوع والسجود.
- حفظ التقييمات اليومية في المتصفح وعرض متوسط آخر ٣٠ أو ٦٠ يومًا.
- دعم الاستخدام دون إنترنت بعد فتح الموقع أول مرة، وتجهيز نموذج الصوت وملفات التطبيق على الجهاز.
- خط JF مرفق محليًا؛ لا يحتاج الموقع إلى تحميل الخط من خدمة خارجية.

## تشغيله واختباره

يتطلب Node.js 20 أو أحدث وpnpm. من مجلد المشروع:

```bash
pnpm install --ignore-scripts
PORT=4173 BASE_PATH=/ NODE_ENV=production pnpm --filter @workspace/salati-training run build
PORT=4173 BASE_PATH=/ NODE_ENV=production pnpm --filter @workspace/salati-training run serve
```

افتحي `http://localhost:4173` للاختبار. يحتاج المتصفح إلى إذن الميكروفون أو الكاميرا عند استخدامهما؛ ويُسمح بهما على `localhost` أو على موقع يعمل عبر HTTPS.

## خطوات تجربة سريعة

1. من **تلاوة** اختاري نصًا، وبدّلي بين **بمساعدة** و**دون مساعدة**.
2. اضغطي **تجهيز النموذج المحلي والبدء**. يحتاج تجهيز النموذج أول مرة إلى الاتصال بالإنترنت. انتظري حتى تظهر حالة **النموذج جاهز**.
3. اضغطي **ابدئي التلاوة**، واسمحي بالميكروفون، واقرئي النص ثم أوقفي الاستماع. ستظهر مقارنة الكلمات والنتيجة التقريبية.
4. شغّلي قراءة الجهاز المرجعية، ثم أعيدي المحاولة إن رغبتِ. احفظي تقييم اليوم ليظهر في سجل الشهر أو الشهرين.
5. افتحي **حركات الصلاة** لتجربة الكاميرا الأمامية والخلفية والتقدير البصري.
6. بعد تجهيز نموذج الصوت وفتح التطبيق مرةً مع الاتصال، افصلي الإنترنت واختبري النصوص والسجل والتقييم على الجهاز.

## حدود النسخة

درجة التلاوة تقيس تقارب الكلمات التي تعرّف عليها النموذج مع النص؛ وقد يخطئ التعرف، ولا يقيّم التجويد أو مخارج الحروف بدقة المعلّم. تقدير الحركة بصري تقريبي ويتأثر بالإضاءة وزاوية الكاميرا، ولا يصدر حكمًا طبيًا أو شرعيًا. قراءة النص المرجعية تعتمد على الأصوات المتاحة في جهاز المستخدم.

لا يُرسل الصوت أو الفيديو أو سجل التقييم إلى خادم. سجل النتائج محلي لهذا المتصفح والجهاز، وقد يُحذف عند مسح بيانات المتصفح. يلزم فتح الموقع مع الاتصال أول مرة وتحميل ملفات النموذج قبل استخدام مراجعة الصوت دون إنترنت.
