# التصور التقني الأولي

## مسار المعالجة

1. يختار المتدرّب الحركة أو جلسة التدريب.
2. تُلتقط إطارات الكاميرا بعد موافقة المستخدم.
3. يستخرج MediaPipe Pose أو MoveNet نقاط الجسم.
4. تحسب قواعد التحليل زوايا مختارة وتتبع انتقال الوضعيات عبر الزمن.
5. تقارن النتائج بنطاقات مرجعية تعليمية راجعها مختصون.
6. تظهر ملاحظة قصيرة وملخص تدريبي.

## نطاق النموذج الأولي المقترح

- البدء بحركتين أو ثلاث يسهل رصدها بصريًا.
- اختبار الرصد في زوايا تصوير وإضاءات مختلفة.
- قياس دقة اكتشاف الوضعيات ومقارنة الملاحظات بمراجعة مدربين ومختصين.
- إظهار درجة الثقة وتجنب التنبيه عند ضعف جودة الصورة أو انخفاض الثقة.

## الخصوصية والمسؤولية

- معالجة الفيديو على الجهاز متى أمكن.
- عدم حفظ الفيديو افتراضيًا.
- توضيح طلب الإذن واستخدام البيانات إذا تطلب التطوير جمعها.
- تقديم الملاحظات بصفتها إرشادًا تعليميًا، لا فتوى ولا حكمًا على صحة الصلاة.
